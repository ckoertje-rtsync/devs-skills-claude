## Overview

This document defines the **derivability partial order** over the Experimental Frames for **{{domain_name}}**. A frame EF_i is derivable from EF_j (written EF_i ≤ EF_j) if the behavioral data of EF_i can be obtained from the behavioral data of EF_j through selection, aggregation, or coarsening operations.

## Partial Order Properties

The derivability relation must satisfy:
- **Reflexivity:** Every EF is derivable from itself (EF_i ≤ EF_i)
- **Antisymmetry:** If EF_i ≤ EF_j and EF_j ≤ EF_i, then EF_i = EF_j
- **Transitivity:** If EF_i ≤ EF_j and EF_j ≤ EF_k, then EF_i ≤ EF_k
